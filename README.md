# PakGpaCalculator 🎓

A modern, accurate GPA and CGPA calculator mobile application tailored specifically for Pakistani universities, built with **React Native** and **Expo**.

## 🌟 Supported Universities

Includes official grading criteria and calculation schemas for:
- **COMSATS University**
- **NUST** (National University of Sciences and Technology)
- **FAST-NUCES**
- **Air University**
- **GCU Lahore** (Government College University)
- **University of Lahore (UOL)**
- **IBA Karachi**
- **University of Sindh**
- **UCP** (University of Central Punjab)
- **Quaid-i-Azam University (QAU)**
- **Virtual University (VU)**
- **University of Agriculture Faisalabad (UAF)**
- **University of Peshawar**
- **AJKU** (University of Azad Jammu & Kashmir)
- **FUUAST** (Federal Urdu University)

## ✨ Features

- **University-Specific Grading Scales**: Pre-configured grading policies (Absolute, Relative, and Continuous percentage-based systems).
- **Semester & CGPA Calculation**: Calculate GPA per semester and cumulative CGPA across academic terms.
- **Course & Credit Management**: Add courses with dynamic credit hours, grades, and marks.
- **Local Persistence**: Save your academic records locally with persistent SQLite storage.
- **Clean & Intuitive Interface**: Sleek UI designed for fast semester entry and real-time score updates.

## 🚀 Tech Stack

- **Framework**: [React Native](https://reactnative.dev/) with [Expo](https://expo.dev/)
- **Language**: TypeScript
- **Navigation**: React Navigation
- **Storage**: SQLite Database (`expo-sqlite`)

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn
- Expo Go app on iOS or Android

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/rana-muhammad-awais/PakGpaCalculator.git
   cd PakGpaCalculator
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npx expo start
   ```

4. Scan the QR code with the Expo Go app (Android) or Camera app (iOS) to run the application on your device.
